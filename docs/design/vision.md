# 项目愿景

## 项目目的

Super Agent 旨在帮助用户在自己的项目与工作环境中，将开发意图推进为可检查的回答、代码变更或验证结果。

用户可以委托一项工作，让 Agent 结合项目上下文进行推理、调用工具、观察结果并继续工作；同时保留对工作方向、操作权限和执行中止的控制。

## 服务的用户与问题

本项目服务于需要在本地项目中阅读代码、修改实现、运行验证和处理开发问题的用户。

一次开发任务通常需要多次“理解上下文、提出行动、执行、观察、调整”。本项目将这些过程组织为连续的工作，使用户能够提出目标、在必要时干预，并检查最终结果。

## 希望提供的价值

- **持续推进工作**：模型能够根据实际操作结果继续处理任务，直到本轮响应结束。
- **保留用户控制**：用户能够审批操作、调整方向和取消执行，系统遵守用户授予的工作范围。
- **保持工作连续性**：对话历史、项目上下文和可恢复的工作环境共同支持后续工作。
- **让结果可检查**：用户能够看到回答、工具活动、变更和验证结果，理解本轮工作产生了什么。

## 如何判断是否接近愿景

- 用户能否在项目上下文中提出真实开发任务，并获得与该任务相关的成果？
- Agent 能否利用工具结果继续推进，而不要求用户手动搬运每一步结果？
- 用户是否能够在执行中保持对授权、方向和停止时机的控制？
- 失败、取消和恢复后，用户能否理解工作停在哪里，并安全地继续？

这些是产品评价方向。具体功能范围由[产品定义](product.md)规定，可验证的质量要求由[质量目标与约束](constraints.md)及相应行为规范细化。
